How I work

Measured, tested, written down

Measure first

A fix starts with a probe that reproduces the problem and ends with the same probe showing the change.

Tests that fail first

A bug gets a test that fails before the fix; CI runs typecheck, unit and end-to-end tests on every push.

Security by default

Least-privilege database roles, secret scans before every commit, and restore drills for backups.

AI where it pays

Plain checks run first; models are called only when judgement is needed.
