How I work

Measured, tested, written down

Measure first

A fix starts with a probe that reproduces the problem and ends with the same probe showing the change.

Tests that fail first

A bug gets a test that fails before the fix; CI runs type checks, unit and end-to-end tests on every push.

Reliable by default

Health checks, monitoring, and backups that are restored every month to prove they work.

AI where it pays

AI speeds up the writing; I own the design, the review and the result. Plain checks run first, models only where judgement is needed.
